# MoCap Doctor

面向 Blender 创作者的 FreeMoCap 动作清理向导。当前版本只支持 Blender 4.3、固定的 FreeMoCap Bake 结构，以及 arue Teto 2.01 和其 MikuMikuRig 控制器。

## 安装

1. 在 Blender 4.3 打开 `Edit > Preferences > Get Extensions`。
2. 从右上角菜单选择 `Install from Disk`，选择发布的 ZIP。
3. 启用 `MoCap Doctor`。面板位于 3D Viewport 右侧栏的 `MoCap Doctor` 页签。
4. 确认工作环境中的 `mmd_tools`、MikuMikuRig 和用于重定向的工具可正常使用。

## 项目约束

- 打开 FreeMoCap 源 `.blend` 后再创建项目。插件会另存工作副本，不覆盖源文件。
- 项目固定为 `30 fps / fps_base 1.0`，只改播放帧率，不平移或缩放关键帧。
- 动捕范围使用绝对帧号，可以晚于第 1 帧开始；范围外的标定动作不处理。
- 项目数据保存在工作文件旁的 `.mocap_doctor/<工作文件名>/`，包括顺序编号的检查点和 JSON 报告。
- `.blend` Scene 是项目状态的权威来源；`project.json` 是便于检查的 UTF-8 镜像。每次恢复旧检查点前还会在 `recovery/` 自动保存当前状态。
- 目标对象必须来自 `arue_teto.blend`，名称和 MMR 约束结构必须保持不变；若 Blender 因重名自动添加 `.001`/`.002` 后缀，插件会把它视为同一固定对象。

## 使用顺序

按面板中的页面前进。每个自动修复先生成预览；播放检查后选择“接受并进入下一步”或“丢弃预览”。底部“上一步/下一步”只浏览页面，不改变数据；“恢复到某步骤执行前”才会打开检查点并把该步骤重置为可执行。手部修复页另有“返回修改坏区间”，会保留已有标注并撤销修复结果。

源骨架 Bake 必须生成覆盖动捕起止帧的关键帧并清空 Pose 约束，验证通过后才删除这些约束实际引用的牵引 Empty。与骨架存在父子关系、链接库对象或带无关子对象的 Empty 会因安全检查保留；丢弃预览可从检查点完整恢复。

手部坏区间和 planted 区间在 NLA 标注编辑器中处理。手部步骤只显示左右手两条轨道，planted 步骤只显示左右脚两条轨道。自动检测结果直接初始化可编辑轨道，不与人工结果另做隐式并集；Strip 名称中的 `[自动]`/`[手动]` 标明来源。默认按 `Ctrl+Shift+I` 标记入点、`Ctrl+Shift+O` 标记出点。只选中一个区间色块时，入点和出点命令只修改该区间；向外延伸会合并覆盖或连接的同方向区间。未选中色块时，入点始终开始创建新区间，出点只完成这个待创建区间。整个色块可以水平平移，也可以上下拖到另一条轨道来纠正左右手或左右脚标错；拖动边缘造成的缩放不会保存，端点应使用入点和出点命令修改。Blender 原生 `Delete/X`、面板删除按钮和“在当前帧拆分”都会写回权威区间数据。快捷键可在插件设置中修改并检查冲突。planted 标注期间，3D 视图会显示青色左脚、橙色右脚空心发光环，中心会露出脚部骨骼；当前脚不在 planted 区间时自动隐藏。标志允许渲染可见，但带有导出排除标记并会在退出标注时删除。

面板参数均提供鼠标悬停说明，完整说明见 `PARAMETERS.md`。

ARP/MMR 重定向仍为人工步骤。第 9 步的 Teto 模板字段只记录你使用的干净模板文件路径，不会自动导入模型；请先把 Teto/MMR 导入当前工作文件，再填写该路径。第 10 步的 Teto 根对象是模型最外层的 mmd_tools Root 空物体，不是 MMR Rig 或骨架。MMD Visual Bake 在固定结构、MMR 输入 Action 和完整帧范围全部通过验证时可以自动执行；检测失败时改为手工 Bake，再使用“检查手工 Bake 并清理 FK”。手工 Bake 若已由 MMR 工具移除约束，插件会改用 MMD Action 中实际存在的骨骼曲线验证；两种路径都会清除 `足/ひざ/足首.L/R` 六根 FK 曲线，并保留足 IK。

导出准备会把 `teto_global_correction` 与 `全ての親` 已有动作按矩阵组合、再次清除腿 FK，并写入 VMD 地面 Z 偏移。开始前会弹出手 IK 回导修复提醒：固定 Teto 的 `手IK.L/R` 是肘部 IK 目标，插件先把可见上肢逐帧烘到真实的 `腕/ひじ/手首.L/R`，再关闭工作副本内的手 IK、为其设定唯一的 Blender 辅助映射名称，并仅删除它的位置与旋转曲线。此过程不会修改 PMX 或原始 Teto 模板，且预览前会创建检查点；上肢烘焙不完整或姿势变化时会阻止导出。其它带关键帧的重名骨骼仍会阻止导出并列出冲突。接受该预览后，确认 MMR 到 MMD 的约束已禁用，并验证隐藏 MMR Rig 后动作仍然正常。最后在插件面板填写 `.vmd` 保存位置并直接导出；插件会以 Teto 的 mmd_tools Root 为活动对象调用导出器，避免文件选择窗口丢失对象上下文。

当前版本不包含 LLM、WSL、Hermes、外部聊天软件连接或通用骨架映射。
