# MoCap Doctor 参数说明

所有距离和速度参数都使用 Blender 当前场景的长度单位。项目固定为 30fps，因此“每帧速度”表示相邻两帧之间的位移。

## 动捕范围

- **开始 / 结束**：真正动作的绝对帧号。范围外的标定板动作会保留，但不会参与 Bake、检测或修复。

## 源动作诊断

- **脚接近地面高度**：脚低于该高度时视为接近地面；调大产生更多候选。
- **足部滑动速度 / 脚跟滑动速度**：超过该每帧位移时报告滑动；调低更敏感。
- **手部跳变距离 / 骨盆跳变距离**：相邻帧位移超过该值时报告跳变；调低会报告更多区间。

## 轻度旋转平滑

- **强度**：0 不改变，1 完全采用平滑结果。
- **半径**：每帧向前后参考的帧数；越大越平滑，也越容易损失快速动作。
- **包含手和前臂**：可能削弱细小、快速的手部动作。

## 源骨架穿地修复

- **地面 Z**：源动作使用的世界坐标地面高度。
- **容差**：允许忽略的小幅穿地。
- **离地间隙**：修复后脚底希望保留的最小间隙。
- **单帧最大抬升**：限制一帧最多抬高骨盆多少。
- **强度**：实际应用计算抬升量的比例。
- **平滑半径**：抬升曲线前后参考的帧数。
- **帧间最大变化**：限制相邻帧抬升量变化，避免骨盆突然跳动。

## Planted 检测

- **接触高度**：脚底距地面不高于该值时才可能判定 planted。
- **XY 速度阈值**：成为 planted 候选允许的最大水平速度。
- **移动判定速度**：超过该速度时视为贴地移动，而不是稳定 planted。
- **垂直速度阈值**：成为 planted 候选允许的最大垂直速度。
- **最短区间**：更短的 planted 段会被丢弃。
- **合并间隔**：间隔不超过该帧数的相邻段会合并。
- **最大锚点漂移**：脚相对区间起始位置允许的最大水平漂移。
- **穿地诊断容差**：低于地面超过该深度时才报告穿地。

检测结果只是初稿。左右脚最终可编辑轨道才是后续脚锁使用的数据。

## Teto 整体与脚部

- **整体旋转 X/Y/Z**：绕世界轴扶正整个 Teto 与 MMR。
- **倾斜参考帧**：脚掌姿态正确、用作基准的帧。
- **倾斜强度**：0 保持原旋转，1 完全压回参考倾斜。
- **压制 X/Y/Z**：选择要压制的旋转轴；Z 通常关闭以保留脚尖朝向。
- **目标地面 Z / 离地间隙 / 容差**：控制模型网格相对地面的高度。
- **单帧最大抬升 / 平滑半径 / 帧间最大变化**：限制整体抬升曲线的幅度和突变。
- **顶点采样步长**：越大越快，但可能漏掉局部最低点。
- **只扫描可见 Mesh**：忽略隐藏部件。
- **重建校正 Z 曲线**：先移除旧曲线，避免重复叠加。

## 脚滑 XY Lock

- **最小修复漂移**：漂移小于该值时不锁定；调低会处理更多区间。
- **锚点**：中位数最抗噪；第一帧保持落脚点；中间帧采用区间中部位置。
- **缓入缓出**：区间前后用于渐入和渐出的帧数。
- **裁掉段首尾**：先从 planted 段两端去掉过渡帧。
- **分析最短区间 / 锁定最短区间**：控制哪些 planted 段可以进入分析与修复。
- **X/Y/Z**：选择锁定脚 IK 的位置轴；Z 通常关闭。

## MMD Bake 与导出

- **Bake 策略**：自动模式只在固定结构全部通过时执行；手动模式由用户 Bake 后再验证并清理腿 FK。
- **VMD 地面 Z 偏移**：导出前写入 `全ての親` 的固定偏移；负值下移，正值上移。
- **手肘回导兼容修复**：生成 VMD 导出预览前会出现确认提醒。固定 Teto 中的 `手IK.L/R` 是 Blender 内用来带动肘部的目标；插件会把当前看得见的上肢动作逐帧烘到真实的 `腕/ひじ/手首.L/R`，关闭这两个 Blender 专用 IK，并清理其位置和旋转曲线。它只改当前工作文件，预览前会创建检查点；不会改 PMX 或原始 Teto 模板。若任一上肢骨骼没有完整 Bake，或转换前后姿势不一致，插件会停止导出并提示恢复检查点。
