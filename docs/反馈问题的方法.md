# 反馈问题的方法（你怎么把看到的问题说清楚）

目标：一句话说清一个缺陷，agent 拿到就能动手，不用来回追问。

方向箭头、指向点怎么摆、怎么检查，见插件目录里的 `方向说明.md`；这份只讲"怎么说"。

## 一句话格式

```
<帧段> <部位> <看到的问题> → <想要的样子>
```

| 你说 | agent 得到 |
|---|---|
| `149-223 右手手心朝镜头` | 帧段 + 部位 + 方向目标 |
| `505-570 食指别弯那么狠` | 帧段 + 部位 + 程度 |
| `11-29 起身再脆一点` | 帧段 + 部位（躯干）+ 力量感 |
| `300 附近左脚踩地打滑` | 大概位置也行，agent 会自己找窗口边界 |

## 部位说法（说人话即可）

手心 / 手背 / 手指尖 / 食指中指无名指小指拇指 / 手腕 /
脚掌 / 脚尖 / 脚心朝向 / 膝盖朝向 / 手肘朝向 / 脚尖朝向（= 迈步方向）/
头看哪 / 身体朝哪。

## 方向说法

- **方向词**（推荐，角色转身也跟着对）：`朝前` `朝后` `角色左` `角色右` `朝镜头` `背离镜头`
  `朝视口` `画面左/右/上/下` `朝脚尖` `朝上/朝下` `朝某个部位`
  - "朝前"指**角色自己**的前（躯干朝向），角色转身它会跟着转；
  - "朝镜头"是从那个部位**指向镜头**，不是相机的视线方向；
  - "朝脚尖"常用于膝盖：说"膝盖内扣 / 别内扣 / 朝外"其实就是它。
- **摆箭头**（最不容易误解）：你摆一支箭头、转到想要的方向，跟 agent 说"朝这支箭头"。
  长期使用的部位箭头用 `MCD_palm.L` 这类名字，做法见 `方向说明.md`。
- **摆点**：放一个小球，意思是"（这个部位）指向这个位置"。
- **方向会变**：给箭头或小球打关键帧，目标方向就逐帧跟着走。
- 直接说世界轴（`+X -X +Y -Y +Z -Z`）也可以，但**角色会转身**，"前面"并不是固定的 −Y。

## 程度说法

- "轻一点 / 再狠一点 / 减半" → 条目力度滑块（或口头说，agent 来调）
- "别超过 N 度" → clamp 模式的 threshold
- 修复写出来后，**条目下面直接有参数滑块**（阈值 / 力度 / 帧范围 / 方向物体），拖就改，
  不用回来说。

## 一个要注意的

- **不要用"左 / 右"指画面上的左右**：`左` / `右` 默认指**角色自己的**左右（`.L` / `.R` 那一侧）。
  正面镜头里角色的左在画面右边——要指屏幕上的方位就直接说"画面左 / 画面右"。
- 一句话只塞一件事；多件事分多条说。

## 修完之后你怎么看

- 在视口里对着**视频对应帧**看**实际网格**，别只看数字。
- 每条修复行首的**眼睛**图标可以单独关掉它，做修前 / 修后对比。
- 参数不满意就拖那条下面的滑块；**同一条要改参数不要重新提一遍需求**。
- 看着还是不对，就带帧号再说一次：`还是不对，F182 这只手应该手心朝前`。

## 预览条目操作速查

- 行首眼睛：单独关这条看对比（A/B）
- 勾选框 + 底部批量滑块：多条一起调力度 / 静音 / 提交 / 撤销
- 条目参数区：改阈值、帧范围、方向物体——自动重写，不堆垃圾 strip
