# 反馈问题的方法（给修复 agent 的话术协议）

目标：一句话说清一个缺陷，agent 拿到就能动手，不用来回追问。

## 一句话格式

```
<帧段> <部位> <看到的问题> → <想要的样子>
```

| 你说 | agent 得到 |
|---|---|
| `149-223 手心朝前` | 帧段 + 部位 + 方向目标 |
| `505-570 食指别弯那么狠` | 帧段 + 部位 + 程度 |
| `11-29 起身再脆一点` | 帧段 + 部位（躯干）+ 力量感 |
| `300 附近左脚踩地打滑` | 大概位置也行，agent 会自己找窗口边界 |

## 部位说法（说人话即可，解剖层负责翻译成骨骼）

手心 / 手背 / 手指尖 / 食指中指无名指小指拇指 / 手腕 /
脚掌 / 脚尖 / 脚心朝向 / 膝盖朝向 / 手肘朝向 / 脚尖朝向（=迈步方向）/
头看哪 / 身体朝哪。

## 方向说法

- **世界轴**：`+X -X +Y -Y +Z -Z`（本文件前方 = **−Y**）
- **词**：`前 后 左 右 上 下 朝镜头`（"前"按脚尖方向推，相机佐证）
- **摆箭头**（最推荐，消歧义最强）：面板"新建方向箭头"在 3D 游标处放一个
  箭头空物体 `mcd_dir_*`，你转到想要的朝向即可——"平行于这个方向"。
- **摆点**："新建指向点"放 `mcd_aim_*`，意思是"（骨）指向这个位置"。
- **方向会变**：给空物体 k 帧动画就行，目标方向逐帧跟着走。

## 程度说法

- "轻一点 / 再狠一点 / 减半" → 条目力度滑块（或口头说，agent 调）
- "别超过 N 度" → clamp 模式的 threshold
- 修复写出来后，**条目下面直接有参数滑块**（阈值/力度/帧范围/方向物体），
  拖就改，不用回来说。

## 不要说的

- 不用报骨名、局部轴、四元数——那是 agent 的活，probe 会推
- 不用说"局部坐标"——一切方向都是世界方向
- 不要一句话塞两件事；多件事分多条说

## 修完之后

agent 必须报：**"修前 X° → 修后 Y°，看 A–B 帧"**（数字来自解剖探头复测，
不是自报自销）。你看到不对就说：`还是不对，F182 这只手应该手心朝前`——
带帧号+期望，agent 会重推候选方向或换方法。

## 预览条目操作速查

- 行首眼睛：单独关这条看对比（A/B）
- 勾选框 + 底部批量滑块：多条一起调力度/静音/提交/撤销
- 条目参数区：改阈值、帧范围、方向物体——自动重写，不堆垃圾 strip
